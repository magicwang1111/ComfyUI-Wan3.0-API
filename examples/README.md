# Example workflows

1. `01_text_to_video.json` - paid text-to-video generation and local preview.
2. `02_first_frame.json` - connect an IMAGE loader to `first_frame`.
3. `03_last_frame.json` - connect an IMAGE loader to `last_frame`; verify account support before production use.
4. `04_first_last_frame.json` - connect two IMAGE loaders in first/last order.
5. `05_multimodal_reference.json` - connect an IMAGE batch and optional VIDEO/AUDIO inputs.
6. `06_query_task.json` - paste a TaskId to recover or inspect an interrupted task.

The generation nodes are billable. Example files never contain credentials.
